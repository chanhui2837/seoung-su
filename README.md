> 단순한 일정 공유를 넘어 분실물·시설예약·멘토링까지 — 춘천 성수고 학생·교사를 위해 만든 올인원 포털

## ✨ 이 사이트만의 특별한 기능 (3가지+)

### 1️⃣ 📅 통합 캘린더 + D-Day (선생님 전용 작성)
- 학사·수행평가·시험·과제를 카테고리별 색상으로 구분
- **선생님만 작성**, 학생은 조회만 가능 (수업 관리 권한 명확화)
- 다음 시험까지 `D-Day` 자동 계산 (헤더에 표시)
- 예: “수학 수행평가 D-2” 처럼 한눈에 확인

### 2️⃣ 🔍 분실물 센터 (사진 업로드)
- 사진 1장으로 분실물/습득물 등록
- 위치·날짜 자동 정리, `보관중 / 주인찾음` 상태 관리
- 댓글로 주인 확인 — “제 거 같아요!” 바로 소통
- 학교에서 가장 필요한 기능 1순위!

### 3️⃣ 🏫 시설 예약 시스템 (선생님 개방 → 학생 예약)
- 체육관 / 음악실 / 동아리실 / 스터디룸 4개 시설
- **처음에는 비어있는 것이 정상**: 시설 담당 선생님이 개방해야 예약 가능
- 날짜 + 시간대(08:00-10:00 등 4타임) 선택, 개방된 시간만 예약 가능
- 이미 예약된 시간은 자동 차단 — 중복 예약 불가
- 본인 예약만 취소, 개방은 개방한 선생님만 삭제 가능

### 4️⃣ 🤝 멘토링 & 재능마켓 (보너스)
- 선배가 후배를 가르치는 멘토링 등록
- 과목별(국어/수학/영어/과학 등) 필터
- 스터디 모집·재능 나눔 카테고리
- “수학 2등급→1등급 노하우 공유” 같은 성수고만의 연결망
- 신청하기 버튼으로 바로 매칭

### 5️⃣ 👥 내 반 (단톡방+개인채팅+투표+일정알림) — NEW
- 처음 입장 시 **반 선택** (예: 3-1) — 같은 반끼리만 단톡방 입장
- **담임은 한 반에 한명** — 이미 담임이 있는 반은 선택 불가
- **단톡방**: 같은 반 학생+담임 전체가 함께 쓰는 그룹 채팅 (실시간 폴링 3초)
- **개인 채팅**: 반 멤버 목록에서 한명 선택해 1:1 대화 (`withUserId` 기반)
- **일정 알림**: 선생님이 `📅 일정 알림`으로 캘린더 일정+단톡 메시지를 동시에 올리면, **앱에서 알림을 켠 학생** 화면에 즉시 토스트(핸드폰 알람처럼) — `PUT /api/settings/notify`로 켜기/끄기, `GET /api/class/notifications` 폴링
- **투표**: 단톡방에서 `📊 투표`로 반장 선거 등 생성, 같은 반 전원이 투표·결과 확인 (한 사람 한 표, 변경 가능, 선생님/작성자만 종료)

## 👤 회원 시스템

- **학생**: `이름 + 학번(5자리, 예: 30101)` + 비밀번호로 가입/로그인
- **선생님**: `이름 + 담당과목` + 비밀번호로 가입/로그인
- 모든 정보는 `data/users.json`에 암호화(bcrypt)되어 **서버에 영구 저장**
- 로그인 후 JWT 토큰으로 인증 유지 (7일간 유효)

| 선생님 | 김선생 | 수학 | 1234 |

## 🖼️ 프로필 사진

- 로그인 후 우측 상단 `프로필` 버튼
- 카메라 아이콘 클릭 → 사진 선택 → 자동 업로드
- `uploads/profiles/` 폴더에 저장, 서버 재시작해도 유지
- “기본으로” 버튼으로 초기화 가능

## 🚀 실행 방법 (로컬)

### 방법 1: 더블클릭 (가장 쉬움)
1. `start.bat` 더블클릭
2. 브라우저에서 `http://localhost:3000` 접속

### 방법 2: 명령어
```bash
npm install
npm start
# http://localhost:3000 에서 확인
```

### 종료
- `Ctrl+C` 또는 `stop.bat` 더블클릭

## 🌐 배포 (오류 없이)

### 옵션 A: Render (추천, 무료)
1. 이 폴더를 GitHub에 업로드
2. https://render.com 에서 New Web Service
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Environment: `PORT=10000` (Render가 자동 주입)
6. Deploy → `https://your-app.onrender.com` 생성

### 옵션 B: Railway / Fly.io
- Dockerfile 포함됨 → 그대로 배포 가능
```bash
docker build -t seongsu .
docker run -p 3000:3000 seongsu
```

### 옵션 C: 학교 내부 서버
- `node server.js`를 PM2로 실행
```bash
npm install -g pm2
pm2 start server.js --name seongsu
pm2 save
```

> **중요**: `data/*.json` 파일이 실제 DB 역할을 합니다. 배포 시 영구 디스크(Persistent Disk)를 연결하거나, 외부 DB로 교체하세요. (현재는 파일 기반이라 재배포 시 초기화될 수 있음 → Render는 디스크 연결 필요)
